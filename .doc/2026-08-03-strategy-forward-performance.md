# 전략별 모의계좌 전진 성과 관리 작업

## 목표

백테스트 정확도를 전략 채택 근거로 삼지 않고, 모의계좌의 실제 체결 기록으로 계좌·전략별 성과를 지속 관찰한다. 같은 기간의 KOSPI·KOSDAQ 수익률과 비교하고, 사용자가 수동으로 유지·축소·중단 여부를 검토할 수 있게 한다.

## 원칙

- 미래 수익이나 백테스트 정확도를 보장하지 않는다.
- 모의계좌 체결 및 저장된 시장가격만 사용한다.
- 계좌 전체와 전략별 성과를 분리한다.
- 불완전한 데이터는 추정값으로 숨기지 않고 품질 사유를 표시한다.
- 수동 검토 결과는 의견으로만 저장하며 주문·전략 상태를 자동 변경하지 않는다.
- 기존 안전 플래그와 승인 흐름은 변경하지 않는다.

## 주요 구현 내용

- 체결 병합 시 `strategy_id`, 버전, 프로필 해시, 승인 원본 ID를 보존한다.
- 같은 초·종목에 여러 전략 체결이 있어도 덮어쓰지 않도록 병합 키를 강화했다.
- 현재 실행 환경의 체결만 성과에 포함한다.
- 매수 시 가상 현금 부족분을 순투입금으로 잡고 KOSPI·KOSDAQ에도 같은 현금흐름을 적용한다.
- 장중 미래 종가 참조를 막기 위해 투입 시점보다 앞선 확정 종가를 벤치마크 매수가로 사용한다.
- 종목 종가나 벤치마크 투입 시점 가격이 하나라도 없으면 관련 수익률을 `null`로 반환한다.
- 전략 소유 불일치나 동일 종목의 전략 공유가 탐지되면 전략 대표 수익률을 차단하고 품질 사유를 표시한다.
- 수동 판단은 `monitor`, `pause`, `reduce`, `increase`, `retire` 의견으로 저장하며 변경 이력도 누적한다.
- 성과 API 실패가 기존 기간 성과 차트 표시를 막지 않도록 UI 호출을 분리했다.

## API와 화면

- `GET /api/performance/forward?strategy_id=`: 계좌 전체 및 전략별 전진 성과 조회
- `PATCH /api/performance/forward/{strategy_id}/review`: 전략 검토 의견과 메모 저장
- 대시보드 성과 탭: 관찰 기간, 순투입금, 평가액, 전략 수익률, KOSPI·KOSDAQ, 지수 대비 초과수익, 데이터 품질, 수동 검토 표시

## 리뷰에서 보완한 사항

- 성과 API 오류가 기존 화면 전체를 막는 문제 수정
- 벤치마크 일부 투입 누락을 정상 수익률로 보이던 문제 차단

- 날짜가 다른 동일 주문번호 및 실행환경 혼합 방지

- 비용 및 데이터 완전성 안내와 수동 검토 문구 명확화

## 알려진 한계와 후속 과제

- 기존 체결에는 브로커 계좌 식별키가 없어 계좌 동일성을 완전히 검증할 수 없으며 `account_identity_unavailable`로 표시한다.
- 순투입금은 실제 입출금 원장이 아니라 매수대금 부족분 방식이므로 브로커 기준 TWR과 다를 수 있다.
- 수수료와 세금은 현재 포함되지 않는다.
- 전략 ID가 없는 과거 체결은 `unattributed`로 남는다.
- 동일 종목을 여러 전략이 공유하는 경우 체결별 배분 원장이 없어 대표 전략 수익률을 차단한다.
- 일별 NAV 영속화와 MDD 관리는 후속 범위다.
- 벤치마크는 직전 확정 종가를 사용하므로 실제 체결 시각의 지수 가격과 차이가 있다.

### 2차 계산 정책

- 전략 TWR의 외부 현금흐름은 실제 입금이 아니라 매수 시 가상현금 부족분이다. 따라서 `synthetic_cashflow` 경고와 함께 비용 전 근사치로 표시한다.
- 계좌 TWR은 15시 30분 이후 저장된 실제 KIS 총자산 스냅샷이 최소 2거래일 존재하고, 해당 기간 입출금이 모두 수동 확인된 경우에만 사용할 수 있다.
- 전략과 지수의 TWR은 같은 확정 거래일 축으로 계산한다.
- 가격 결측이 한 번 발생하면 이후 가격이 복구돼도 해당 TWR 체인은 자동 재개하지 않는다.
- 마지막 지수 확정일 뒤 체결이 존재하면 조용히 누락하지 않고 NAV 계산을 차단한다.
- 수수료·세금 원천값을 모의계좌 API에서 확인할 수 없으므로 0원으로 간주하지 않는다.

### 2차 API

- `GET /api/performance/forward`: v2 성과 요약. 대용량 일별 시계열은 제외
- `GET /api/performance/forward/{strategy_id}/nav`: 저장된 일별 NAV·TWR·MDD 조회
- `GET /api/performance/account-cashflows`: 수동 계좌 현금흐름 조회
- `POST /api/performance/account-cashflows`: 입출금·배당·이자 등 수동 등록 및 확인
- 성과 탭에서 발생 시각·종류·금액·근거·확인 여부를 직접 입력할 수 있다.

### 남은 운영 조건

- 실제 계좌 TWR은 기능 배포 이후 장 마감 잔고가 최소 2거래일 축적되어야 활성화된다.
- 모의계좌의 실제 수수료·세금 원천 데이터는 아직 확보되지 않았으므로 순수익률은 제공하지 않는다.
- 기존 체결의 계좌키는 신뢰할 수 있는 주문내역 동기화로 매칭된 경우에만 보완한다.
