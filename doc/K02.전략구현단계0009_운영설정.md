# 전략 구현 단계 0009: 운영 설정과 프로필

## 단계 목표

자율 전략 런타임이 요구하는 위험 설정을 모든 전략 프로필과 프리셋에 보수적으로
제공하고, 플랫폼 및 실거래가 명시적 다중 동의 없이는 활성화되지 않도록 한다.

## 위험 프로필 기본값

기본 및 마이그레이션 프로필에 다음 값을 적용한다.

| 설정 | 기본값 |
|---|---:|
| 거래당 최대 위험 | 0.5% |
| 총 오픈 포지션 위험 | 2.0% |
| 섹터 최대 노출 | 20.0% |
| 평균 거래대금 참여 한도 | 0.5% |
| 데이터 최대 나이 | 60초 |
| 최소 현금 보유 | 20.0% |
| 허용 국면 | neutral, bull, low_volatility |

기존 프로필의 명시된 값은 보존하고 누락된 위험 필드만 기본값으로 채운다.
`risk`와 `backtest` 하위 객체를 깊은 병합하여 일부 설정을 가진 기존 전략도 새
필수 필드를 잃지 않는다.

## 생명주기 안전

- `selected=true`는 실행 승인으로 해석하지 않는다.
- 상태가 없는 기존 전략은 마이그레이션 시 `draft`가 된다.
- 국내 및 미국 간편 프리셋은 검증 결과를 포함하더라도 `paper_passed`까지만
  생성되고, `approved` 전환은 별도 승인 절차가 필요하다.
- 프리셋에도 런타임 필수 위험 한도와 허용 시장 국면을 명시했다.

## 환경 설정

```text
AUTONOMY_ENABLED=false
AUTONOMY_TRADING_ENV=demo
AUTONOMY_REQUIRE_APPROVAL=true
AUTONOMY_ENABLE_LIVE_TRADING=false
AUTONOMY_LIVE_OPT_IN=false
```

실전 자율 운영은 자율 플랫폼의 환경·실거래 허용·명시 동의뿐 아니라 기존 전역
`TRADING_ENV=real`, `DRY_RUN=false`, `ENABLE_LIVE_TRADING=true`까지 모두
충족해야 한다. 하나라도 없으면 런타임이 실패 폐쇄한다.

## 축소 및 청산 설정 보완

`TradeIntent`에 주식 수량이 아닌 `reduce_pct`를 추가했다.

- `REDUCE`: `(0, 100]` 범위 비율 필수
- `EXIT`: 정확히 `100`
- 다른 행동: `reduce_pct` 금지
- 결정론적 리스크 엔진이 `floor(전략 소유 수량 × 비율 / 100)`으로 수량 계산
- 계산 결과가 1주 미만이면 주문을 거부

따라서 AI는 포지션 축소 비율을 계획할 수 있지만 실제 주식 수량을 지정하거나
전략 소유 수량을 초과할 수 없다.

## 검증 상태

프로필 마이그레이션, 프리셋 승인 상태, 안전한 환경 기본값, 실거래 명시 동의,
축소 비율 수량 산정 테스트를 작성했다. 사용자 요청에 따라 테스트 실행은 최종
단계로 유보했다.
