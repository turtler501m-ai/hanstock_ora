# 전략 구현 단계 0010: 포트폴리오 비중 완결

## 목적

체결된 보유액뿐 아니라 아직 체결되지 않은 관리 주문의 예약 노출까지 종목,
시장, 섹터, 전략 비중에 반영한다. 병렬 전략과 재시작 복구 주문이 동일
비중 여유를 중복 사용할 수 없게 한다.

## 필수 위험 입력

`RiskLimits`에 `max_strategy_exposure_pct`를 필수 한도로 추가했다.

`RiskSnapshot`은 다음 실제 체결 노출과 예약 노출을 구분해 받는다.

- `position_value`: 해당 종목 실제 보유 평가액
- `market_exposure_value`: 시장 실제 보유 평가액
- `sector_exposure_value`: 섹터 실제 보유 평가액
- `strategy_exposure_value`: 전략 실제 보유 평가액
- `reserved_symbol_exposure_value`
- `reserved_market_exposure_value`
- `reserved_sector_exposure_value`
- `reserved_strategy_exposure_value`

모든 값은 신뢰 스냅샷의 필수 비음수 유한값이다. 누락, 음수, NaN 및 무한대는
신규 위험 주문을 fail-closed로 거부한다.

## 수량 상한

신규 매수의 권위 수량은 기존 손절·현금·유동성 상한과 다음 비중 여유 중
최솟값이다.

```text
종목 여유 = 총자산×종목한도 - 실제 종목노출 - 예약 종목노출
시장 여유 = 총자산×시장한도 - 실제 시장노출 - 예약 시장노출
섹터 여유 = 총자산×섹터한도 - 실제 섹터노출 - 예약 섹터노출
전략 여유 = 총자산×전략한도 - 실제 전략노출 - 예약 전략노출
```

현금 여유에서도 시장 전체 활성 매수 예약 노출을 차감한다. 따라서
`available_cash`가 아직 미체결 주문을 반영하지 않은 브로커 현금이어도 같은
현금을 다시 계획하지 않는다. 저장소 예약 CAS가 최종 동시성 방어를 계속
담당한다.

위험감소 `reduce`, `exit`, `sell`은 비중을 초과한 상태에서도 계속 허용되며
전략 소유 보유수량만 상한으로 사용한다.

## 예약 노출의 권위 계산

`list_active_reserved_exposures()`는 활성 위험예약을 전략 포지션 및 최신
미종결 매수 관리 주문과 결합한다.

```text
pending exposure =
  (requested_qty - filled_qty) × requested_price
```

`RiskDecision.exposure_reservation_limits`에는 실제 체결 노출만 차감한 종목,
시장, 섹터, 전략별 활성 예약 총허용액을 기록한다. Orchestrator는 승인
노출액, symbol, sector key와 이 한도들을 `reserve_risk_budget()`에 전달한다.
저장소는 `BEGIN IMMEDIATE` 안에서 기존 활성 예약 노출을 차원별로 다시
합산한다. 따라서 같은 runtime cycle에서 생성되어 시작 스냅샷에 아직 없던
두 번째 주문도 한도를 넘으면 원자적으로 거부된다.

관리 주문이 생성되기 전 예약 구간에는 예약 `cash_amount`를 사용한다.
부분체결 수량은 실제 holdings 노출에 들어가므로 예약 노출에서는 잔여
미체결분만 계산한다. 이로써 부분체결 금액을 실제 노출과 예약 노출에
이중계산하지 않는다.

Runtime은 계좌·시장별 활성 예약을 조회하고:

- symbol별 합계
- market 전체 합계
- instrument의 필수 `sector`별 합계
- strategy별 합계

를 각 불변 `RiskSnapshot`에 주입한다. 예약 종목의 instrument/sector가
시장 스냅샷에 없으면 추정하지 않고 실행을 차단한다.

## 검증 코드

- 종목·섹터·전략 예약이 신규 수량을 제한하는 테스트
- 비중 초과 중 위험감소 주문이 계속 허용되는 테스트
- Runtime이 예약을 네 가지 노출에 정확히 귀속하는 테스트
- 부분체결 주문에서 잔여수량만 예약 노출로 계산하는 저장소 테스트

사용자 지시에 따라 테스트는 작성만 했으며 실행하지 않았다. 배포와
실주문도 수행하지 않았다.
